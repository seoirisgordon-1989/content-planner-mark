Как настроить синхронизацию

Статусы и даты хранятся в твоём GitHub Gist — приватном, бесплатно. Настройка один раз:

  1. Иди на github.com/settings/tokens/new
  2. Note: planner-sync
  3. Срок: No expiration
  4. Разрешение: поставь галочку gist
  5. Нажми Generate token, скопируй токен (ghp_…)
  6. Вставь в поле слева → Сохранить ↑

Токен сохранится в браузере. На другом устройстве введи тот же токен → Загрузить ↓. Данные загрузятся из Gist.
